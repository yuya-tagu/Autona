## 実況・解説（Commentary）

既定は Web 版（サイドバー「実況・解説」= 共有ビューの `/web/commentary`。ADR-005 S4b）。設定 → 一般「実況・解説パネルを従来版（Qt）で表示する」を ON にして再起動すると Qt 版に戻る（S4c で削除予定）。以下は Web 版で確認する。

- [ ] 12 スロット固定のカードで名前・チーム・役割・アイコン・コメント・Twitter を入力できる
- [ ] 名前フィールドでローカル選手 DB の補完が効き（フォーカスで候補が出る）、確定でチーム/Twitter が自動入力される
- [ ] 候補にマウスを乗せただけで Enter を押しても選手は読み込まれない（打った文字のまま）。矢印キーで選んだ候補は Enter で、クリックした候補はそのまま読み込まれる
- [ ] 大会を読み込むと名前の候補がその大会の参加者に絞られ、大会の URL を消すと選手 DB 全体に戻る（ブラウザで開いたページも同じ）
- [ ] カード左のグリップをドラッグしてカードを並び替えると、スロットの内容ごと入れ替わる
- [ ] 「配信に表示」を ON にすると右のプレビューに反映される（2/3/4 名でレイアウトが可変）
- [ ] オーバーレイにはカードの並び順（スロット順）で左から表示される（チェックした順ではない）
- [ ] 表示 ON が 4 名に達すると残りのチェックボックスが無効化される
- [ ] 0 名時はオーバーレイのバーが非表示、1 名時は中央ワイド 1 枚になる
- [ ] OBS URL（`/layout/commentators/index.html`）をコピーしてブラウザで表示できる
      ※旧 tag*.html を OBS に登録していた場合はこの URL に差し替える
- [ ] `curl -X POST http://localhost:5107/update-commentary-1 -H "Content-Type: application/json" -d "{\"gamerTag\":\"test\"}"` がスロット 1 に反映される
- [ ] 再起動後も実況・解説者のデータが復元される（旧バージョンからの初回起動では旧データの name/team/本名/Twitter/追加情報が引き継がれる）
- [ ] デザインを切り替えるとプレビューと OBS URL が変わり、再起動後も選んだデザインが残る（Qt 版と同じ `settings.json` のキー）
- [ ] 「実況・解説の色」のテーマ / アクセント / 「大会のカラーに合わせる」がプレビュー（オーバーレイ）に反映される
- [ ] 入力欄を右クリックすると編集メニュー（元に戻す・やり直し・切り取り・コピー・貼り付け・すべて選択）だけが出る。選択した文字の上ではコピーだけ、それ以外の場所ではメニューが出ない（戻る・再読み込み・ページのソースは出ない）
- [ ] ブラウザで `http://127.0.0.1:5107/web/commentary` を開いて編集すると、デスクトップの表示とオーバーレイに反映される。両方で同じ欄を開いていても、入力中の欄は相手の更新で上書きされない。ただし打っている途中で相手がその欄を書き換えたら、離れたときに相手の値が残る（打ちかけは送られない。その後に打ち直した文字は送られる）

## 外部制御 API（`/api/v1/`・実装時に確認）

> 仕様: [design/external-control-api.md](design/external-control-api.md)。自動テストは作らず本節を手動でなぞる。
> `python main.py` 起動後、curl 等で叩いて UI / `out/` / OBS / WS で反映を確認する。

### リグレッション（既存を壊していないこと・最優先）

- [ ] 既存 `/score`（POST）・`/scoreboard1-team1-scoreup` 等の旧ルートが従来通り動く
- [ ] Web UI（`/scoreboard`・`/team`・`/web`）が表示され、双方向同期する
- [ ] OBS ブラウザソース／`out/` 出力が従来通り更新される
- [ ] デスクトップ UI・グローバルホットキーの操作が従来通り効く
- [ ] Socket.IO の `program_state` / `program_state_update` 購読が従来通り届く

### 新 API の動作

- [ ] `GET /api/v1/state` がフル状態を `{"ok":true,"data":...}` で返す
- [ ] `GET /api/v1/health` が `activeBoard` / `currentGame` / `revision` 等を返す
- [ ] `POST /api/v1/scoreboards/1/teams/1/score:adjust {"delta":1}` でスコア +1 され、OBS/Web に反映
- [ ] 同操作を `Idempotency-Key` 付きで再送しても二重加算しない
- [ ] `POST /api/v1/scoreboards/1:clear`（confirm 無し）が 409 CONFIRMATION_REQUIRED で**状態を変えない**
- [ ] `confirm:true` 付きで clear が実行される
- [ ] 重い操作（`POST /api/v1/tournament` 等）が 202 で返り、完了が WS で観測でき、実行中の同種要求が 409
- [ ] 範囲外 `{n}`（0 や 4）が 400 INVALID_ARGUMENT になる
- [ ] board3 に board1/2 用操作（score:adjust 等）を投げると明示拒否される
- [ ] 書き込み操作が操作ログ（INFO）に出る／読み取りは出ない
- [ ] OBS 機・操作端末が**別 PC**でも LAN 内から `/api/v1/...` に到達できる（運用想定の確認）
