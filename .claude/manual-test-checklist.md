# 手動テストチェックリスト

自動テストで守れない動作確認手順。PR レビュー時になぞる。

---

## 起動・終了

- [ ] `python main.py` でウィンドウが表示される
- [ ] ウィンドウタイトルにバージョン番号が含まれる
- [ ] 閉じるボタンで正常終了する（ハングしない）
- [ ] 2回目の起動でレイアウトが復元される

## スコアボード基本操作

- [ ] 選手名を入力して Enter → `out/` フォルダに反映される
- [ ] スコア変更 → `out/program_state.json` に即座に反映
- [ ] チーム入れ替え（Swap）で選手名・スコア・キャラが正しく入れ替わる
- [ ] Best Of 変更 → `best_of`, `best_of_text`, `first_to` 等が全て更新される
- [ ] Clear All で選手名・スコア・キャラが全てクリアされる

## ゲーム選択

- [ ] ゲーム変更 → キャラクターリストが更新される
- [ ] ゲーム変更 → ステージリストが更新される（has_stages の場合）
- [ ] ゲーム変更後、選手ウィジェットのキャラ選択が動作する

## Web UI（ブラウザ確認）

- [ ] `http://localhost:5000/scoreboard` にアクセスできる
- [ ] デスクトップ側の変更がブラウザにリアルタイム反映される
- [ ] ブラウザからスコア変更 → デスクトップ側に反映される

## 実況者（Commentary）

- [ ] 実況者数を変更できる
- [ ] 実況者名を入力して反映される
- [ ] 実況者数を減らした後、`out/` の commentary データが正しく更新される

## サムネイル生成

- [ ] 選手・ゲーム設定後にサムネイル生成が成功する
- [ ] 生成された画像が正しく表示される

## ホットキー

- [ ] Settings でホットキー設定を変更できる
- [ ] 設定したホットキーが機能する（スコアアップ等）

## トーナメントデータ

- [ ] Start.gg URL を入力してトーナメントデータを取得できる
- [ ] セット選択 → 選手データが自動入力される
- [ ] 自動更新が機能する（タイマー表示確認）
