## 配信設定（Stream Settings）

- [ ] タイトルを手で書き換える → 欄の下が「手入力したタイトルです」になる。別の大会を読み込んでも手入力のまま。**再起動しても手入力のまま**。欄を空にしてから大会を読み込み直すと自動のタイトルに戻る

- [ ] **デスクトップで**「サムネイルをクリップボードにコピー」→ クリップボードに画像が入り、Discord などへ貼り付けられる（サムネを生成するまではボタンが押せない。Qt 版の「未生成ならコピーで生成してからコピー」は無くなった）
- [ ] ブラウザで `http://127.0.0.1:5107/web/stream` を開いても同じ操作ができ、デスクトップの表示に反映される（チャンネル一覧とオプションは設定なので、もう一方は開き直したときに追いつく）。この PC のブラウザでは画像コピーのボタンが出る

- [ ] キャラを選ぶ（アイコンつきの一覧）→ カラーの選択（アイコン + 番号）が押せるようになり、オーバーレイにそのキャラ・カラーのアイコンが出る。カラーを変えるとアイコンが変わる。別キャラのスキン（スマブラ SP の Dr. Mario 等）も、そのキャラのアイコンになる。キャラの欄の × で空にするとアイコンが消える
- [ ] ゲームを切り替える → 前のゲームのキャラは空になり、キャラの一覧が新しいゲームのものになる（切り替わるまでキャラ・カラーの欄は押せない）
- [ ] 更新前のビルドで Top 8 に国・キャラ・カラーを入れて保存した状態で起動する → ページの国・キャラ・カラーに保存した選手のものが出る（空にならない）。オーバーレイも今までどおり
- [ ] 表示ラベルを打つ → オーバーレイの見出しが変わる。空にして欄を離れても欄は空のまま「TOP 8」が薄く出て、オーバーレイは「TOP 8」。その後、別のブラウザで開いた同じページから表示ラベルを打つと、その値が出る
- [ ] スコアを打つ → オーバーレイはまだ変わらず、「反映」が押せるようになる。「反映」→ 打った試合だけが確定し、勝者が次の試合に進む（オーバーレイも）。打っていない試合のスコア・結果はそのまま
- [ ] RESET（GF のリセット）の欄は、GF で Losers 側が勝ったときだけ入力できる
- [ ] スコアを打ちかけのまま、別のブラウザで開いた同じページから試合を「反映」する → 打ちかけのスコアが消えて、反映されたスコアが出る。別のブラウザで選手の名前を変えただけなら、打ちかけは残る
- [ ] 「全リセット」→ 確認が出る。「キャンセル」なら何も変わらない。「リセット」で全試合のスコアと確定が消える
- [ ] 大会を読み込んでいない状態で「大会結果を読み込む」→「先に大会を読み込んでください。」。大会を読み込んでから押す →「大会結果を読み込んでいます。…」→ 少し後に選手・国・キャラ・スコアが入り、オーバーレイに取り込んだ選手のキャラアイコンが出る。押した直後にもう一度押すと「大会結果を読み込み中です。…」
- [ ] 進行中の試合がある大会を取り込んだ後、別の試合のスコアだけを打って「反映」→ 進行中の試合は確定にならない（Qt 版は全試合を送っていたので確定になっていた。S4i の挙動差）
- [ ] デザインを切り替えるとプレビューと OBS URL が変わり、再起動後も選んだデザインが残る（`settings.json` の `top8.selected_design`）。OBS URL をコピーして OBS のブラウザソースに貼ると表示できる
- [ ] 「TOP 8 の色」のテーマ / アクセント / 「大会のカラーに合わせる」がプレビュー（オーバーレイ）に反映される
- [ ] ホットキー Ctrl+Shift+P（Top 8 の取り込み）が今までどおり動き、ページに結果が出る
- [ ] ブラウザで `http://127.0.0.1:5107/web/top8` を開いて編集すると、デスクトップの表示とオーバーレイに反映される。LAN の別の PC から（トークン付きの URL で）開いても操作できる。トークン無しで書き込むと「アクセストークンが必要です」が 1 回だけ出る
- [ ] ヘッドレス（`python main.py --headless`）でブラウザから `/web/top8` を開き、選手・スコア・取り込みができる
- [ ] **IME 実機ゲート**: 名前・所属タグ・表示ラベルの日本語入力（変換・確定の Enter。Enter で送信もフォーカス移動もしない）、国・キャラの欄での日本語の絞り込み

## 統計情報

Web 版だけ（サイドバー Data の「統計情報」= 共有ビューの `/web/stats`。ADR-005 S4k）。統計の取得と書き込みは core の `StatsService`（S3e-5）、試合一覧は core の `AnalysisService`（S4j）。Qt 版（統計情報パネルと、そのサブタブの試合一覧）は S4k で削除済み。ほかの React のパネルと同じ共有ビューに出る。

- [ ] サイドバーで「統計情報」「Top 8 表示設定」「実況・解説」を交互に開くと、それぞれのページが出る。ページの切り替えでビューは再読み込みされない。統計情報に戻ると、最後に選んでいたタブが選ばれている
- [ ] タブが 4 つ（直近の対戦 / 戦績 / 大会履歴 / この大会の試合一覧）出る。上の行は、ボード 1 の両選手の名前があるとき「アップセットファクター: N    |    A vs B」、片方でも空なら「A vs P2」のように対戦カードだけ
- [ ] 大会を読み込み、start.gg の選手のいるセットをボード 1 に読み込んで「反映」→「統計情報を取得する」→「統計情報を取得しています。…」が出て、少し後に 3 つのタブの表が埋まる（応答を待つ間はボタンが押せない）。統計のオーバーレイ（`layout/upset_factor` ほか）と同じ値になっている
- [ ] 直近の対戦: 「A  1W (50%)    -    1W (50%)  B    [2 セット]」の形の 1 行と、日付（この PC の日付）・大会 + イベント（2 行）・ラウンド・スコア・勝者の表。Qt 版と同じ勝敗数・勝率になる
- [ ] 戦績 / 大会履歴: 選手ごとの見出しと表。大会履歴の日付は「2026/November/04」の形（月は英語。今までどおり）
- [ ] セットを読み込んで「反映」する前は、上の行と見出しの選手名は前の選手のまま（反映済みの名前を出す。OBS と同じ。S4k の挙動差）
- [ ] この大会の試合一覧: 大会を読み込んでいない状態で「start.gg からデータを取得」→「大会が選択されていません」。大会を読み込むと「「start.gg からデータを取得」を押してください」に戻る
- [ ] 大会を読み込んで「start.gg からデータを取得」→「フェーズ情報を取得中...」→「取得中 n/m」→「N 試合」になり、表が出る（取得中はボタンが押せない）。phase group が複数ある大会では、ラウンドの前に「フェーズ / グループ · 」が付く
- [ ] 表の見出しを押すと、その列で昇順 → もう一度押すと降順に並ぶ（既定は Round の昇順 = ブラケットの順。Qt 版はラウンド名の文字の順だった。S4k の挙動差）。絞り込みの欄に選手名かラウンドを打つと、その行だけになる（大文字小文字は区別しない）
- [ ] 大きな大会（試合が数百〜千以上）で一覧を取り、絞り込みの欄に選手名を続けて打つ → 文字の入力が引っかからない（表は少し遅れて追いついてよい。行の仮想化はしていない）。並べ替えの列を切り替えたときも、数秒止まるようなことがない
- [ ] 一覧を取った後にもう一度「start.gg からデータを取得」→ 取得中も前の一覧が出たままで、終わると新しい一覧に替わる（Qt 版と同じ）
- [ ] 試合一覧を取ったまま別のパネルへ移って戻る / ページを再読み込みする → 同じ一覧が出る（結果は core が持つ）。LAN の別の PC で開いても同じ一覧が出る
- [ ] 大会を読み込み直す・別の大会にする・解除する → 一覧が消えて、元の文言に戻る。取得中に大会を変えても、前の大会の行が後から出ない
- [ ] 取得中に別のブラウザから「start.gg からデータを取得」を押す →「試合一覧を取得中です。…」が出て、取得は 1 本のまま
- [ ] ブラウザで `http://127.0.0.1:5107/web/stats` を開いても同じものが見え、取得できる。LAN の別の PC から（トークン付きの URL で）開いても取得できる。トークン無しで取得を押すと「アクセストークンが必要です」が 1 回だけ出る
- [ ] ヘッドレス（`python main.py --headless`）でブラウザから `/web/stats` を開き、統計の取得と試合一覧の取得ができる
- [ ] 英語（設定で言語を English）にすると、タブ・ボタン・文言が英語になる（試合一覧の列名は日本語でも英語のまま。今までどおり）
