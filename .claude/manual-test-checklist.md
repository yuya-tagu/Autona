## 配信設定（Stream Settings）

Web 版だけ（サイドバー Setup の「配信設定」= 共有ビューの `/web/stream`。ADR-005 S4e）。処理は core の `StreamService`（S4d）。Qt 版は S4e で削除済み。実況・解説と同じ共有ビューに出る。

- [ ] サイドバーで「配信設定」と「実況・解説」を交互に開くと、それぞれのページが出る（どちらから先に開いても、再起動後に最後に開いていた方から始めても）。ページの切り替えでビューは再読み込みされず、入力中の内容が残る
- [ ] 配信設定を一度も開かずに大会を読み込む → 配信設定を開くと、タイトルが「大会名 ft. 上位の参加者 ... and more! - 略称」で入っている（参加者の取得が終わる前は「大会名 - 略称」）。欄の下に「自動生成されたタイトルです」と出る
- [ ] タイトルを手で書き換える → 欄の下が「手入力したタイトルです」になる。別の大会を読み込んでも手入力のまま。**再起動しても手入力のまま**。欄を空にしてから大会を読み込み直すと自動のタイトルに戻る
- [ ] 大会を読み込んだ直後（参加者の取得中）にタイトル欄へ打ち始め、取得が終わってから欄を離れる → 打った文字が残る（自動のタイトルに置き換わらない）
- [ ] 「コピー」でタイトルがクリップボードに入る（メモ帳などに貼り付けられる）
- [ ] 「追加」でチャンネル名・URL を入れて保存 → 一覧に増え、配信先として選ばれる（下の「配信先 URL」も変わる）。片方が空だと保存できず「両方を入力してください」が出る
- [ ] 選択中のチャンネルを「編集」→ 名前・URL を変えて保存 → 配信先が新しい URL になる。「編集」→「削除」→ 確認で「キャンセル」なら残り、「削除」なら消えて配信先が空になる。チャンネルを選んでいない（URL を直接入力した）ときは「編集」が押せない
- [ ] 「配信先 URL」に直接 URL を打つと配信先になる（コンボは「選択しない」になる）。再起動しても一覧と配信先が残る
- [ ] 団体アイコン / サムネの「画像を選択」→ プレビューが出て、`layout/stream_org_{icon,thumbnail}.png` が長辺 512 / 1920 以下の PNG になる（スマホで撮った .jpg も読める）。画像でないファイルを選ぶと「画像を読み込めませんでした…」、20MB を超えるファイルは送らずに「画像が大きすぎます」が出る
- [ ] 「登録した配信団体の素材を削除」→ 確認で削除すると両方「未登録」になり、背景が「配信団体サムネイル」だったら「大会バナー」に戻る（何も登録していないときはボタンが押せない）
- [ ] 背景とスタイルのラジオが独立して選べる（スタイルを変えても背景の選択が外れない）。オプションを変えて再起動すると選択が残る
- [ ] 「配信サムネイルを生成」→「サムネイルを生成しています…」とボタンの無効化 → 終わるとプレビューと「保存しました: out/stream/thumbnail_...jpg」。生成中も UI が固まらない（オフラインでも保存済み / 既定のバナーで生成される）。団体サムネ未登録で「配信団体サムネイル」を選んで生成するとエラーの文言が出る
- [ ] **デスクトップで**「サムネイルをクリップボードにコピー」→ クリップボードに画像が入り、Discord などへ貼り付けられる（サムネを生成するまではボタンが押せない。Qt 版の「未生成ならコピーで生成してからコピー」は無くなった）
- [ ] ブラウザで `http://127.0.0.1:5107/web/stream` を開いても同じ操作ができ、デスクトップの表示に反映される（チャンネル一覧とオプションは設定なので、もう一方は開き直したときに追いつく）。この PC のブラウザでは画像コピーのボタンが出る
- [ ] LAN の別の PC から（トークン付きの URL で）開くと、画像コピーの代わりに「画像を開く / 保存」が出て、押すと新しいタブで画像が開く。トークン無しで書き込むと「アクセストークンが必要です」が 1 回だけ出る
- [ ] ヘッドレス（`python main.py --headless`）で大会を読み込むと `out/stream/title.txt` にタイトルが出る。ブラウザで `/web/stream` を開くとチャンネル・素材・サムネ生成も操作できる

- [ ] サイドバーの「サムネイル」で React のページが出て、ゲームと両側の選手が入っていればプレビューが描かれる（入っていなければ「先にゲームを選択してください」等の文言）

- [ ] ズーム・横位置・縦位置は、打っている途中では保存も描き直しもせず、Enter か欄を離れたときに保存されて描き直される
- [ ] SCORE で選手名・ラウンドを変えて（反映の前でも）サムネイルに戻るとプレビューと動画タイトルが新しい試合になる。v1 の `PATCH /api/v1/scoreboards/1/teams/2/players/1` で変えてから戻っても同じ。何も変えずに戻っても 1 回描く。SCORE を開いている間はサムネイルの描画が走らない（ログに `Thumbnail render complete:` が出ない）
- [ ] ページを開いたままスコアだけを変えても、プレビューは描き直されない
- [ ] 背景の「自分で選んだ画像」を画像なしで選ぶとファイル選択が開く。画像を選ぶと「画像: thumbnail_background_….png」が出て、次のプレビューの背景になる。「大会バナー」「デフォルトの画像」に戻すとその背景になる

- [ ] 「サムネイルを作成」→ 「保存しました: …/out/thumbnails/…png」がスナックバーとボタンの下に出て、`out/thumbnails/` に PNG と JPG ができる。作成中と背景のアップロード中はボタンが押せない

- [ ] 「既定に戻す」→ 確認で「キャンセル」なら何も変わらず、「既定に戻す」で全ゲームの設定とアップロードした背景が既定に戻る
- [ ] **SCORE の「サムネイル生成」と X 投稿・`http://127.0.0.1:5107/scoreboard1-get-thumbnail-png` がページの設定どおりに描く**（ページで所属タグを外すと SCORE の生成でも出ない）。チーム戦のボードではチーム名のチェックが効く

## 大会情報（Tournament Info）

Web 版だけ（サイドバー Setup の「大会情報」= 共有ビューの `/web/event`。ADR-005 S4g）。大会の設定・解除は `core/TournamentService`、アイコン / バナーは `core/TournamentMediaService`、入力欄は `core/TournamentInfoService`、カラーは `core/ColorService`（S4f）。Qt 版は S4g で削除済み。実況・解説・配信設定と同じ共有ビューに出る。

- [ ] サイドバーで「大会情報」「配信設定」「実況・解説」を順に開くと、それぞれのページが出る。ページの切り替えでビューは再読み込みされず、入力中の内容が残る
- [ ] 「大会 URL」に event URL を入れて「設定（アイコン・バナーも取得）」→「大会を読み込んでいます…」→「大会を読み込みました。」。大会名などが入り、少し後にアイコン / バナーのプレビューが変わる。取得中は「大会アイコン / バナーを取得中…」が出て、「大会からダウンロード」「Autona の既定に戻す」が押せない。UI は固まらない
- [ ] 再起動して大会情報を開くと、「大会 URL」に前回の URL が入っていて、起動時の読み直しの「大会を読み込んでいます…」→「大会を読み込みました。」がページに出る
- [ ] ページの URL 欄に別の URL を打ちかけたまま、サイドバーの大会ボタン →「大会を設定」で別の大会を設定する → ページの URL 欄がその大会の URL に変わり（打ちかけは消える）、状態もその大会のものが出る。そのまま「設定」を押してもサイドバーで設定した大会のまま（S4g レビュー M1 / M3）
- [ ] 大会 A を読み込み中に大会 B を設定する（A の読み込みが遅いとき）→ 最後に B の大会名などが残り、状態は B の結果（S4g レビュー M2）
- [ ] admin の URL（`start.gg/admin/tournament/<大会>/brackets/<id>`）を入れて「設定」→「管理画面の URL からイベントを探しています…」→ 少し後に大会が読み込まれる。イベントの無い admin URL（id を壊す）なら「この URL からイベントを見つけられませんでした…」が出て、読み込み済みの大会はそのまま

- [ ] 「再取得」→ 同じ URL でも大会を読み直す（アイコン / バナーは取り直さない）
- [ ] 「解除」→ 確認が出る。「キャンセル」なら何も変わらない。「解除する」で大会情報が空になり、URL の欄も空になり、サイドバーのゲームボタンが「ゲームを選ぶ」に戻り、ページのゲームも「未選択」になる。サイドバーの大会ボタン →「大会の設定を解除」も同じ
- [ ] 大会名・イベント名・場所・参加人数・開催日を打つ / 選ぶ → OBS（大会名などを出すオーバーレイ）に反映される。参加人数に数字以外を打つと「0〜999999 の整数を入力してください。」が出て送られない。参加人数を空にして欄を離れると、何も送らずに元の数に戻る。開催日の年を 1 桁ずつ打っても、途中でエラーが出ない（4 桁の 2000〜2999 年になってから送る）。**開催日は再起動しても残る**（OBS の開始日の表示は今までどおり）
