---
description: Git の変更内容から PR 説明文を生成する
---

Pull Request の説明文を以下の手順で生成してください。

1. `git diff main...HEAD` で PR に含まれる全変更を把握する
2. `git log main..HEAD --oneline` でコミット一覧を確認する
3. 変更内容を分析し、以下のフォーマットで PR 説明文を作成する:

```markdown
## 概要
{なぜこの変更が必要か 1-2文で}

## 変更内容
- {変更項目1}
- {変更項目2}
- ...

## 影響範囲
- [ ] デスクトップアプリ (PyQt6)
- [ ] Web UI (React)
- [ ] ビルド設定
- [ ] その他

## テスト確認
- [ ] Web UI ビルド (`npm run build`) 成功
- [ ] デスクトップアプリ起動・タブ表示確認
- [ ] exe ビルド成功
```

ガイドライン:
- 日本語で書く
- 変更内容は具体的にファイル名や機能名を含める
- マークダウンコードブロック内に出力し、そのままコピーできるようにする
