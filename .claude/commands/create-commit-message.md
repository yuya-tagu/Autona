---
description: Git の変更内容からコミットメッセージを生成する
---

Git のコミットメッセージを以下の手順で生成してください。

1. `git status` と `git diff` で現在の変更内容を把握する
2. 変更を分析し、コミットタイプを判定する:
   - `feat`: 新機能
   - `fix`: バグ修正
   - `refactor`: リファクタリング
   - `style`: UI/デザイン変更
   - `build`: ビルド設定変更
   - `chore`: その他メンテナンス
3. 以下のフォーマットでコミットメッセージを作成:
   ```
   <type>(<scope>): <簡潔な説明>

   <詳細な変更内容（必要に応じて）>
   ```

ガイドライン:
- コミットメッセージは日本語で書く
- 1行目は72文字以内
- scope は任意だが推奨（例: `desktop`, `web`, `build`, `stats`）
- 何を変えたか・なぜ変えたかを具体的に書く

`git commit -m` でそのまま使える形で出力する。
