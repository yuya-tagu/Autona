現在のブランチの変更を以下の観点でレビューしてください。

## 手順

1. `git diff main...HEAD` で全変更を把握する
2. `CLAUDE.md` を読み、プロジェクトの規約を確認する
3. 変更内容を規約に照らしてレビューする

## レビュー観点

### デスクトップアプリ (PyQt6)
- QDockWidget に `setWindowTitle()` が設定されているか
- `STATE_VERSION` の更新が必要なレイアウト変更がないか
- `objectName` が既存ウィジェットと重複していないか
- シグナル接続が適切か（メモリリークの可能性）

### Web UI (React)
- Redux state のデフォルト値変更の影響範囲
- 未使用の import が残っていないか
- `BACKEND_PORT` を使った fetch が適切か

### 共通
- 既存コードのパターンに合っているか
- 不要なコード（未使用関数・変数）が残っていないか
- エラーハンドリングが適切か

## 出力形式

1. **要修正** — マージ前に修正が必要
2. **推奨** — 検討すべき改善点
3. **良い点** — 適切な実装
