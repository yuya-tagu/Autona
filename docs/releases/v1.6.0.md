Autona v1.6.0

## 新機能

- **スコアボードデザイナー: Figma 連携と Game History 用 SVG 形式を追加** — Figma で作成したデザインを取り込めるようになり、Game History 表示用の SVG 形式にも対応しました
- **セット選択の高速化** — セット一覧を手動取得＋キャッシュ方式に変更し、選択時の待ち時間を短縮しました
- **大会アイコン / バナーのダウンロードボタンを統合** — Tournament Info パネルから一括でダウンロードできるようになりました

## 修正

- 結果画像の保存時に PNG と JPG が二重に保存される問題を解消しました
- 統計情報の取得が全リクエスト失敗する問題を修正しました
- スコアボードの「Best of」変更時の例外で、それ以降の自動保存が停止することがある問題を修正しました
- 選手アバター出力の不具合と、まれな異常終了（access violation）の原因を修正し、安定性を改善しました

## アップデート時の注意

- 設定・選手データベース・ダウンロード済みゲーム画像は更新後もそのまま引き継がれます

## v1.0.7 / v1.1.0 をご利用の方へ（一度だけ手動更新が必要です）

v1.0.7 / v1.1.0 の自動更新機能に不具合があり、アプリ内の「ダウンロードしてインストール」を実行しても更新が適用されません（アプリが終了するだけで、再起動しても旧バージョンのままになります）。お手数ですが、以下の手順で一度だけ手動更新をお願いします。**一度最新版にすれば、次回からの自動更新は正常に動作します。**

1. Autona を終了する
2. 最新版をダウンロード: https://github.com/yuya-tagu/Autona-releases/releases/latest （release-windows.zip）
3. zip を展開し、中の `Autona` フォルダの中身を、いま使っている Autona のフォルダ（Autona.exe がある場所）に上書きコピー
4. Autona.exe を起動し、Help → About でバージョンが最新になっていることを確認

※ 選手データベースや設定、ダウンロード済みのゲーム画像は上書きしても消えません。
