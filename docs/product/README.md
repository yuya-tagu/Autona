# docs/product

既存 Autona の**プロダクト視点**の記録。何ができるか、誰がどう使うか、
どの業務フローに乗るかを書く。実装の「どう作るか」は書かない（→ `architecture/`）。

## 置くもの

- 中核ワークフロー（外部連携で壊してはいけない時系列フロー）
- 画面・ユーザー操作・利用シナリオ・大会配信オペの業務フロー
- 「絶対に劣化させてはいけない」機能（リグレッション禁止リスト）

> 機能カタログと、変更時に効く範囲（運用制約・リグレッション禁止）は [features.md](features.md) に集約する。
