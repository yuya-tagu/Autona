# 旧バージョン（v1.0.7 / v1.1.0）向け手動更新の告知・手順

作成日: 2026-07-10

## 背景

v1.0.7 / v1.1.0 に同梱されたアップデータには、更新ヘルパー（`apply_update.ps1`）を
`DETACHED_PROCESS` 付きで起動するバグがあり、**「ダウンロードしてインストール」を
実行してもアプリが終了するだけで更新が適用されない**（無音で不発。詳細は
[.claude/release-runbook.md](../../.claude/release-runbook.md) の地雷表参照）。

- 修正は **v1.1.1（2026-07-03 公開）** に同梱済み。v1.1.1 以降の自動更新は正常
- 更新時に動くのは**インストール済みの旧バージョン側**のアップデータであるため、
  修正版を公開しても v1.0.7 / v1.1.0 の利用者は自動では抜け出せない（鶏と卵）
- 該当世代はアプリ内から正常な更新体験ができないため、**アプリ外（Discord 等）での
  告知と、一度だけの手動更新**が必要

対象整理:

| 利用中バージョン | 自動更新 | 必要な対応 |
|----------------|---------|-----------|
| v1.0.7 / v1.1.0 | ❌ 無音で不発 | **一度だけ手動更新**（以降は自動更新が正常化） |
| v1.1.1 以降 | ✅ 正常 | 不要 |
| v1.0.6 以前 | 未検証（旧方式） | 手動更新を推奨（同じ手順でよい） |

バージョンは アプリの About 画面（Help → About Autona）で確認できる。

## 手動更新手順（ユーザー向け）

1. Autona を完全に終了する
2. 最新版の `release-windows.zip` をダウンロード:
   <https://github.com/yuya-tagu/Autona-releases/releases/latest>
3. zip を展開し、中の `Autona` フォルダの**中身すべて**を、現在使っている
   Autona のインストールフォルダ（`Autona.exe` がある場所）に**上書きコピー**する
4. `Autona.exe` を起動し、About 画面でバージョンが最新になっていることを確認する

補足（ユーザーの不安への先回り）:

- 選手データベース・設定・取得済みゲーム画像（`user_data/`・`layout/game_images` 等)は
  zip に含まれないため、**上書きコピーで消えない**
- 心配な場合はコピー前にインストールフォルダごとバックアップしてよい

## 告知文テンプレート（Discord 貼り付け用）

> **【重要】v1.0.7 / v1.1.0 をご利用の方へ: 一度だけ手動更新をお願いします**
>
> v1.0.7 / v1.1.0 の自動更新機能に不具合があり、アプリ内の「ダウンロードして
> インストール」を実行しても**更新が適用されない**ことが分かりました
> （アプリが終了するだけで、再起動しても旧バージョンのままになります）。
>
> お手数ですが、以下の手順で一度だけ手動更新をお願いします。
> **一度最新版にすれば、次回からの自動更新は正常に動作します。**
>
> 1. Autona を終了する
> 2. 最新版をダウンロード: https://github.com/yuya-tagu/Autona-releases/releases/latest （release-windows.zip）
> 3. zip を展開し、中の `Autona` フォルダの中身を、いま使っている Autona のフォルダ（Autona.exe がある場所）に上書きコピー
> 4. Autona.exe を起動し、Help → About でバージョンが最新になっていることを確認
>
> ※ 選手データベースや設定、ダウンロード済みのゲーム画像は上書きしても消えません。
> ご不明点はこのサーバーでお気軽にどうぞ。

いまのバージョンの確認方法もセットで案内する場合は「Help → About Autona で
バージョンを確認できます。v1.1.1 以降の方は対応不要です」を文末に足す。

## 運用ルール

1. **リリースノートに定型文を毎回含める**（v1.0.7 / v1.1.0 世代はいつ更新を試みるか
   分からないため、当面すべてのリリースノートに載せ続ける）:

   > **v1.0.7 / v1.1.0 をご利用の方へ**: 自動更新の不具合により、この世代からは
   > アプリ内更新が動作しません。本ページの `release-windows.zip` を展開し、
   > 中の `Autona` フォルダの中身をインストールフォルダに上書きコピーしてください
   > （設定・選手データは消えません）。一度更新すれば以降の自動更新は正常です。

2. Discord での告知は上記テンプレートを使い、ピン留めする
3. 廃止判断: Discord 等で v1.0.7 / v1.1.0 利用者からの問い合わせが十分な期間
   （目安: 2026-10 以降）観測されなくなったら、定型文の掲載をやめてよい
