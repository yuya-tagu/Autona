# 同梱フォントとライセンス / Bundled Fonts

Autona が同梱するフォントと、その出典・ライセンスの対応表です。
未使用フォントは公開準備時に整理し、実使用のもののみを残しています。

| フォント | 場所 | ライセンス | 著作権者 / 出典 |
|---------|------|-----------|----------------|
| LINE Seed JP | `LINESeedJP/` | SIL OFL 1.1 → [OFL-1.1.txt](OFL-1.1.txt) | LY Corporation — https://seed.line.me/ |
| 源暎Mゴシック (GenEi M Gothic) | `GenEiMGothic/` | SIL OFL 1.1 → [OFL-1.1.txt](OFL-1.1.txt) | おたもん — https://okoneya.jp/font/ |
| Roboto Condensed | `RobotoCondensed.ttf` | Apache License 2.0 → [Apache-License-2.0.txt](Apache-License-2.0.txt) | Google — https://fonts.google.com/specimen/Roboto+Condensed |

オーバーレイ (`layout/include/`) にも Noto Sans / Roboto / Roboto Condensed を
同梱しています。ライセンス本文は本フォルダの `OFL-1.1.txt`（Noto Sans）/
`Apache-License-2.0.txt`（Roboto 系）を参照してください。

> 再配布が許可されていない「たまねぎ楷書激」は公開準備時に削除し、
> 該当テンプレートは LINE Seed JP にフォールバックしています。
